# Controles

## Teclado
| Ação | Jogador 1 | Jogador 2 |
|---|---|---|
| Acelerar/ré/esterçar | W A S D | setas |
| Freio de mão | Espaço | Ctrl direito |
| Recolocar o carro | Shift esquerdo | Shift direito |
| Trocar câmera | C | V |
| Olhar para trás (segurar) | Q | `/` ou Num 0 |

Câmeras (4): padrão, mais próxima, capô, para-choque sem carro. Retrovisor só nas câmeras internas (B liga/desliga).

## Globais
`Esc` pausa/volta, `P` pausa, `R` reinicia, `X` campeonato, `H` alta resolução, `G` garagem, `M` som, `N` próxima música.

## Menus
↑↓ movem entre itens, ←→ mudam/ligam a opção; item selecionado sempre destacado. Pistas: ↑↓ entre seções (pista/horário/clima), ←→ muda a opção. Campeonato: ↑↓ botões, ←→ etapa já alcançada. Garagem: ↑↓ alterna J1/J2, ←→ carros, Espaço troca cor, arrastar gira o carro.

## Toque
Pad ◀▶, Acelerar, Freio, Mão, pausa e recolocar; sem atalhos de teclado na interface. 2 jogadores desativado em tela vertical.
